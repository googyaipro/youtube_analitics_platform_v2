# 📖 მომხმარებლის სრული სახელმძღვანელო და ანალიზის მეთოდოლოგია

მოგესალმებით **YouTube Analytics Platform**-ზე — კონკურენტების მონიტორინგის, ვირუსული ანომალიების გამოვლენისა და ხელოვნური ინტელექტის (Gemini) სიღრმისეული ანალიზის პლატფორმაზე.

## 1. 🔑 პირადი API გასაღებების დამატება (BYOK)

პლატფორმა მუშაობს უსაფრთხო **BYOK (Bring Your Own Key)** მოდელით: თქვენ იყენებთ Google-ისა და YouTube-ის თქვენს პირად უფასო კვოტებს. ყველა გასაღები იშიფრება **AES-256 (Fernet)** ალგორითმით და იკითხება მხოლოდ ოპერატიულ მეხსიერებაში მოთხოვნის დროს.

### სად კონფიგურირდება:
მარცხენა მენიუში გადადით განყოფილებაში **«🔑 პროფილი»** (*Profile*).

### ნაბიჯი 1. YouTube Data API v3 გასაღები
* **დანიშნულება:** YouTube-ის უახლესი მონაცემების მიღება (ნახვები, მოწონებები, კომენტარები, გამოქვეყნების დრო, გამომწერები).
* **სად მივიღოთ (უფასოდ):**
  1. გადადით [Google Cloud Console](https://console.cloud.google.com/)-ზე.
  2. ჩართეთ ბიბლიოთეკა **YouTube Data API v3** (*APIs & Services → Library*).
  3. განყოფილებაში *Credentials* შექმენით API გასაღები (**«Create Credentials» → «API key»**).
* **დამატება:**
  1. ჩასვით გასაღები ველში **«1. YouTube Data API გასაღები»**.
  2. დააჭირეთ **«🧪 გასაღების შემოწმება»**. წარმატების შემთხვევაში სტატუსი გახდება **`🟢 ვალიდური`**.

### ნაბიჯი 2. Google Gemini API გასაღები
* **დანიშნულება:** ინტელექტუალური AI-ანალიტიკოსი, ვიდეოს წარმატების დეკონსტრუქცია და ყოველდღიური დაიჯესტები.
* **სად მივიღოთ (უფასოდ):**
  1. გახსენით [Google AI Studio](https://aistudio.google.com/).
  2. დააჭირეთ **«Get API key» → «Create API key»**.
* **დამატება:**
  1. ჩასვით გასაღები ველში **«2. Gemini API გასაღები»**.
  2. დააჭირეთ **«🧪 გასაღების შემოწმება»**.
* **ნაბიჯი 3:** ქვემოთ დააჭირეთ ლურჯ ღილაკს **«💾 API გასაღებების შენახვა»**.

## 2. 🤖 Telegram შეტყობინებების გამოწერა

Telegram-ის დაკავშირება საშუალებას გაძლევთ მიიღოთ ავტომატური დაიჯესტები და სწრაფად გააანალიზოთ ვიდეოები ბოტის მეშვეობით.

### ნაბიჯი 1. დაკავშირების კოდის გენერირება
1. პროფილის გვერდზე მარჯვენა სვეტში დააჭირეთ **«🔗 Telegram-ის დაკავშირება»**.
2. სისტემა შექმნის:
   - პირდაპირ ბმულს: **`👉 Telegram ბოტის გახსნა`**.
   - 16-ნიშნა ერთჯერად კოდს (მაგ.: `a1b2c3d4e5f67890`).

### ნაბიჯი 2. აქტივაცია Telegram-ში
1. გახსენით ბოტი Telegram-ში და გაგზავნეთ:
   ```text
   /start <თქვენი_16_ნიშნა_კოდი>
   ```
2. ბოტი დაადასტურებს დაკავშირებას: *«🎉 ანგარიში წარმატებით დაუკავშირდა!»* და დააყენებს თქვენს ენას.
3. ვებ-პლატფორმაზე დააჭირეთ **«🔄 სტატუსის შემოწმება»**.

### ნაბიჯი 3. განრიგის მორგება
1. გადადით გვერდზე **«⚙️ არხების ნაკრებები»** (*Channel Sets*).
2. აირჩიეთ ნაკრები, მიუთითეთ გაგზავნის დრო, დროის სარტყელი და კვირის დღეები.
3. ჩართეთ **«✅ ავტომატური გაგზავნა განრიგით»** და შეინახეთ.

## 3. 📊 ველების, მეტრიკებისა და გრაფიკების განმარტება

### «🏠 მთავარი» (Home)
* **KPI ბარათები:** არხები ნაკრებში, გაანალიზებული ვიდეოები, სრული ნახვები, საშუალო ნახვები ვიდეოზე და ვირუსული ჰიტები ($Outlier \ge 2.0x$).
* **ტოპ ვიდეოების ცხრილი:**
  - **ნახვები:** მიმდინარე საერთო რაოდენობა.
  - **Velocity (VPH — ნახვები საათში):** რეალური სიჩქარე, რომლითაც YouTube ვიდეოს ამჟამად ურჩევს მაყურებელს.
  - **Outlier Score (ანომალიის კოეფიციენტი):**
    - `1.0x`: არხის ჩვეულებრივი ნორმა.
    - `📈 1.5x – 1.9x`: ნორმაზე მეტი (+50–90%).
    - `🚀 2.0x+`: ვირუსული გარღვევა გამომწერების ბაზის მიღმა.
  - **Engagement Rate (ER%):** $\frac{\text{მოწონებები} + \text{კომენტარები}}{\text{ნახვები}} \times 100\%$.
  - **ბეიჯები:** `🎬 ვიდეო` / `📱 Shorts`, `🚀 ჰიტი 2.5x`, `⚡ 250 ნახვა/სთ`, `💎 140% გამომწერებზე`.
  - **«🧠 AI ანალიზი»:** სიღრმისეული რეპორტი (ვერდიქტი, ჰუკი და შეფუთვა, ტრენდი, რეკომენდაცია).

### «📈 დინამიკა» (Dynamics)
* **სვეტოვანი დიაგრამები:** გამომწერებისა და ნახვების განაწილება კონკურენტებს შორის.
* **ვირუსულობის მატრიცა (Scatter Chart):** ნახვები vs Outlier Score / VPH.
* **ფორმატების განაწილება:** Shorts-ისა და გრძელი ვიდეოების თანაფარდობა.

### «⚙️ არხების ნაკრებები»
* თემატური ნიშების მართვა და არხების დამატება `@handle`-ით, ბმულით ან Channel ID-ით.

### «💬 AI ანალიტიკოსი»
* პირდაპირი სტრატეგიული კითხვები Gemini-სთან მიმდინარე არხების ნაკრებზე.

### «📋 ლოგები და AI დიაგნოსტიკა»
* პრომპტებისა და პასუხების სრული ტელემეტრია მოდელის ვერსიითა და დაყოვნებით.
