# 📖 Полное руководство пользователя и Методология Анализа

Добро пожаловать в **YouTube Analytics Platform** — интеллектуальную систему мониторинга конкурентов, выявления аномальных всплесков внимания и глубокого качественного AI-анализа вирального контента.

## 1. 🔑 Как добавить персональные API-ключи (BYOK)

Платформа работает по безопасной модели **BYOK (Bring Your Own Key)**: вы используете свои персональные бесплатные квоты Google и YouTube. Все ключи шифруются симметричным алгоритмом **AES-256 (Fernet)** и расшифровываются исключительно в оперативной памяти в момент выполнения запроса.

### Где настраивать:
В левом боковом меню перейдите в раздел **«🔑 Профиль»** (*Profile*).

### Шаг 1. Ключ YouTube Data API v3
* **Для чего нужен:** сбор свежих метаданных с YouTube (просмотры, лайки, комментарии, дата публикации, длительность, подписчики).
* **Где получить (бесплатно):**
  1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/).
  2. Создайте проект (или выберите существующий) и включите библиотеку **YouTube Data API v3** (*APIs & Services → Library*).
  3. В разделе *Credentials* нажмите **«Create Credentials» → «API key»**.
* **Как добавить:**
  1. Вставьте ключ в поле **«1. Ключ YouTube Data API v3»** (формат: `AIzaSy...`).
  2. Нажмите кнопку **«🧪 Проверить ключ»**. Система сделает тестовый запрос к YouTube. При успешном тесте статус изменится на **`🟢 Валиден`**.

### Шаг 2. Ключ Google Gemini API
* **Для чего нужен:** работа интерактивного AI-аналитика, глубокий качественный деконструкционный разбор виральности роликов и генерация ежедневных дайджестов ниши.
* **Где получить (бесплатно):**
  1. Откройте [Google AI Studio](https://aistudio.google.com/).
  2. Нажмите **«Get API key» → «Create API key»**.
* **Как добавить:**
  1. Вставьте ключ в поле **«2. Ключ Gemini API»** (формат: `AIzaSy...`).
  2. Нажмите кнопку **«🧪 Проверить ключ»**. Система проверит соединение с моделью Gemini.
* **Шаг 3:** Нажмите внизу синюю кнопку **«💾 Сохранить ключи API»**. Ключи будут надежно зашифрованы и сохранены.

## 2. 🤖 Как зарегистрировать подписку на Telegram-рассылку

Привязка Telegram позволяет получать регулярные утренние/вечерние executive-дайджесты по вашим наборам каналов и оперативно разбирать ролики через команды бота.

### Шаг 1. Генерация кода привязки в профиле
1. В разделе **«🔑 Профиль»** обратите внимание на правую колонку **«🤖 Интеграция с Telegram»**.
2. Нажмите кнопку **«🔗 Привязать Telegram»**.
3. Система сформирует:
   - Прямую ссылку на бота: **`👉 Открыть Telegram-бота`**.
   - Ваш персональный одноразовый 16-значный код привязки (например: `a1b2c3d4e5f67890`).

### Шаг 2. Активация в Telegram
1. Нажмите на ссылку перехода в бота или найдите вашего бота в Telegram.
2. Отправьте команду:
   ```text
   /start <ваш_16-значный_код>
   ```
   *(либо просто отправьте 16-значный код обычным сообщением в чат)*.
3. Бот ответит подтверждением: *«🎉 Аккаунт успешно привязан!»*, автоматически настроит системное меню на ваш язык и удалит мешающие клавиатуры.
4. В веб-интерфейсе нажмите **«🔄 Проверить статус»** — появится статус `🟢 Привязан` и кнопка **«🔔 Отправить тестовое уведомление»** для быстрой проверки связи.

### Шаг 3. Настройка расписания рассылки
1. Перейдите во вкладку **«⚙️ Наборы каналов»** (*Channel Sets*).
2. Выберите набор или создайте новый и настройте блок **Расписание**:
   - **Время отправки дайджеста:** укажите желаемое время (например, `09:30` или `18:00`).
   - **Часовой пояс:** выберите ваш реальный пояс (например, `Europe/Moscow`, `Europe/Berlin`, `Asia/Tbilisi`, `UTC`).
   - **Дни недели:** выберите дни (например, Пн-Пт или все 7 дней).
   - **Чекбокс:** включите галочку **`✅ Включить авто-отправку по расписанию`**.
3. Нажмите **«Сохранить набор»**. В указанное время бот будет автоматически присылать выжимку трендов.

## 3. 📊 Что значат поля, показатели и диаграммы

### Вкладка «🏠 Главная» (Обзор и факторный анализ)

#### 1. Карточки KPI вверху страницы:
* **Каналов в наборе:** количество каналов конкурентов, отслеживаемых в активной группе.
* **Проанализировано видео:** общее число собранных роликов.
* **Суммарно просмотров:** валовый объем внимания, аккумулированный набором.
* **В среднем на видео:** среднее арифметическое просмотров (ориентир ниши).
* **Виральных хитов:** количество аномальных роликов с множителем $Outlier \ge 2.0x$.

#### 2. Таблица «Топ видео и факторный анализ»:
* **Название видео и Канал:** заголовок и автор ролика со ссылкой на YouTube.
* **Просмотры:** фактическое текущее количество просмотров.
* **Скорость (VPH — Views Per Hour):**
  $$\text{VPH} = \frac{\text{Просмотры}}{\max(\text{Возраст видео в часах}, 1)}$$
  *Отражает живой темп прироста прямо сейчас.* Старое видео со 100 000 просмотров имеет ~10 VPH (оно остановилось). Новое видео, набравшее 6 000 за 3 часа, имеет **2 000 VPH** — алгоритм YouTube прямо сейчас продвигает его.
* **Множитель к норме (Outlier Score):**
  $$\text{Outlier} = \frac{\text{Просмотры ролика}}{\text{Историческая медиана просмотров этого канала}}$$
  *Главная метрика системы:*
  - `1.0x` — Базовая норма постоянных зрителей канала.
  - `📈 1.5x – 1.9x` — Выше нормы (+50–90%). Тема вызвала повышенный интерес.
  - `🚀 2.0x+` — Аномальный вирусный хит. Алгоритмы вывели видео за пределы подписчиков в «Рекомендованные» (Browse Features).
* **Вовлеченность (ER% — Engagement Rate):**
  $$\text{ER} = \frac{\text{Лайки} + \text{Комментарии}}{\text{Просмотры}} \times 100\%$$
  - Норма: `1.0% – 2.0%`.
  - `💬 ER ≥ 2.5%`: высокая вовлеченность, дискуссионная или эмоциональная тема.
* **Бейджи:**
  - `🎬 Видео` / `📱 Shorts` — формат контента.
  - `🚀 Хит 2.5x` — коэффициент превышения нормы канала.
  - `⚡ 250 просм/ч` — высокая скорость набора просмотров.
  - `💎 140% к подп.` — видео набрало больше просмотров, чем вся база подписчиков канала (пробитие «пузыря подписчиков»).
* **Кнопка «🧠 AI Разбор»:** запускает глубокий анализ ролика нейросетью Gemini (Вердикт, Хук и упаковка, Оседланный тренд, Совет автору).

### Вкладка «📈 Динамика» (Визуализация ниши)

* **🏆 Топ каналов по подписчикам (Bar Chart):** показывает иерархию масштаба каналов в вашей нише.
* **👁️ Суммарные просмотры каналов (Bar Chart):** выявляет, кто реально генерирует максимальный трафик, а не просто обладает старой базой подписчиков.
* **🎯 Матрица виральности / Scatter Chart (Просмотры vs Outlier Score / VPH):**
  - Каждая точка — отдельное видео.
  - *Нижняя зона:* стандартные ролики с обычной динамикой.
  - *Правый нижний угол:* старые видео с большими просмотрами, но нулевой скоростью.
  - *Верхняя зона:* взрывные ракеты с высоким Outlier Score и горячим VPH.
* **📊 Соотношение форматов (Pie / Donut Chart):** распределение между Shorts и классическими длинными видео.

---

### Вкладка «⚙️ Наборы каналов» (Channel Sets)

* **Название и Описание:** тематический маркер группы каналов (например, *«Зарубежный AI»*, *«Финтех Подкасты»*).
* **Вкладка «📺 Каналы в наборе»:**
  - Добавление канала: поддерживает `@handle` (например, `@mkbhd`), прямую ссылку на канал (`https://youtube.com/@name`) или Channel ID (`UC...`).
  - Карточки каналов: аватар, число подписчиков, суммарные просмотры и дата обновления.
  - Кнопка **«Синхронизировать сейчас»**: внеочередной сбор свежих роликов через YouTube API.

---

### Вкладка «💬 AI Аналитик» (Интерактивный консультант)
* Поле свободного ввода вопроса к модели Gemini.
* Нейросеть анализирует контекст вашего набора каналов и отвечает на любые стратегические вопросы:
  - *«Какие темы набирали максимальный VPH за последнюю неделю?»*
  - *«Сравни приемы в заголовках топ-3 лидеров ниши»*
  - *«Предложи 5 идей роликов на основе виральных хитов этого месяца»*.

---

### Вкладка «📋 Логи и AI Диагностика» (System Logs)
* **AI & LLM Телеметрия:** аудит обращений к модели Gemini (текст промпта, версия модели, задержка в секундах, сырой JSON-ответ и результат парсинга).
* **Системные события:** логи вебхуков Telegram, планировщика расписаний и фоновых задач.
* **Интерактивный тестер:** отправка тестового запроса к модели для быстрой проверки ключа.

## 4. 🤖 Быстрые команды Telegram-бота

| Команда | Действие |
| :--- | :--- |
| `/menu` | Открыть интерактивное меню с кнопками |
| `/top` | Топ-10 лучших видео с бейджами и быстрыми кнопками разбора |
| `/explain <№>` | Запустить глубокий AI-разбор видео № из топа |
| `/digest` | Сгенерировать свежий Executive-дайджест ниши |
| `/sets` | Посмотреть наборы каналов и переключить активный |
| `/status` | Проверить статус ключей API и расписания |
| `/lang` | Переключить язык (`ru`, `en`, `de`, `fi`, `ka`) |
| `/help` | Краткая подсказка по всем командам |
