# 📖 Руководство пользователя и Методология Анализа

Добро пожаловать в **YouTube Analytics Platform** — интеллектуальную систему мониторинга конкурентов, выявления аномальных всплесков внимания и глубокого качественного AI-анализа вирального контента.

---

## 1. 🚀 Архитектура и принцип работы платформы

Платформа решает главную проблему контент-мейкеров и аналитиков — **отделяет реальные алгоритмические тренды от фонового шума**.

1. **Тематические наборы каналов (Channel Sets)**:
   - Вы группируете каналы конкурентов по нишам (например: *«AI Инструменты»*, *«Крипта»*, *«Финтех»*).
   - Каждый набор анализируется изолированно, выявляя внутренних лидеров и специфику темы.
2. **Прямая интеграция с YouTube Data API v3**:
   - Система опрашивает официальный API YouTube, собирая актуальные метрики: просмотры, лайки, комментарии, дату публикации и длительность роликов.
3. **Безопасная архитектура BYOK (Bring Your Own Key)**:
   - Вы используете свои собственные ключи YouTube API и Google Gemini API.
   - Ваши ключи шифруются симметричным шифрованием **AES-256 (Fernet)** и расшифровываются исключительно в оперативной памяти в момент выполнения запроса.
4. **Регулярные дайджесты в Telegram**:
   - В заданное время бот присылает структурированную аналитическую сводку по активному набору прямо в чат Telegram.

## 2. ⚙️ Как система производит анализ (Методология)

Абсолютное число просмотров обманчиво: 50 000 просмотров для канала-миллионника — это провал, а для канала с 5 000 подписчиков — ошеломляющий вирусный взрыв. Поэтому система использует **относительную нормированную оценку**:

1. **Расчет исторического базового уровня (Baseline)**:
   - Для каждого канала система вычисляет медианную норму просмотров по его недавним видео.
   - Это позволяет объективно сравнивать каналы разных размеров на одной шкале.
2. **Факторный анализ аномалий**:
   - Каждое видео оценивается по отклонению от привычной нормы данного автора, текущей скорости набора просмотров и вовлеченности аудитории.
3. **Фильтрация формата контента**:
   - Ролики автоматически классифицируются на **🎬 Длинные видео** и **📱 Shorts** (до 60 секунд), так как алгоритмы их продвижения принципиально различаются.

## 3. 📊 Ключевые показатели и метрики

### 🚀 Outlier Score (Множитель к норме / Фактор аномалии)
Основной показатель алгоритмического прорыва ролика. Показывает, во сколько раз видео превзошло средний базовый уровень данного канала:
* **`1.0x` (Базовый уровень / Обычный ролик)**: Видео набрало стандартный объем просмотров ядра канала.
* **`📈 1.5x – 1.9x` (Выше нормы / High Performer)**: Ролик сработал значительно лучше обычного. Тема или оформление вызвали повышенный интерес постоянных зрителей.
* **`🚀 2.0x+` (Вирусный прорыв / Viral Outlier)**: Настоящий аномальный хит. Алгоритм YouTube начал активно рекомендовать видео за пределами подписной базы канала в «Рекомендованные» (Browse Features) и «Похожие видео» (Suggested). Такие ролики обязательно нужно изучать для заимствования хуков и идей.

---

### ⚡ Velocity (VPH — Views Per Hour / Скорость в час)
Текущий алгоритмический импульс ролика:
$$\text{VPH} = \frac{\text{Просмотры}}{\max(\text{Возраст видео в часах}, 1)}$$
* **Зачем нужен VPH**: Видео трехмесячной давности со 100 000 просмотров уже выгорело и имеет скорость ~10 VPH. Видео, вышедшее 3 часа назад и набравшее 6 000 просмотров, имеет **2 000 VPH**. Именно оно определяет тренд текущего момента.
* **Бейдж `⚡ 100+ views/h`**: Сигнал о продолжающемся активном притоке трафика.

---

### 💬 Engagement Rate (ER% — Коэффициент вовлеченности)
Отражает эмоциональную отдачу и готовность аудитории взаимодействовать с автором:
$$\text{ER} = \frac{\text{Лайки} + \text{Комментарии}}{\text{Просмотры}} \times 100\%$$
* **`1.0% – 2.0%`**: Стандартная вовлеченность для широкого информационного контента.
* **`💬 ER ≥ 2.5%`**: Высокий резонанс. Зрители активно делятся мнением, спорят в комментариях и одобряют подачу. Это мощнейший сигнал для алгоритма ранжирования YouTube.

---

### 💎 Views-to-Subscribers Ratio (% Просмотров к подписчикам)
Показывает способность ролика пробить «пузырь подписчиков»:
$$\text{Views-to-Subs} = \frac{\text{Просмотры}}{\text{Число подписчиков канала}} \times 100\%$$
* **`< 20%`**: Контент потребляется только частью ядра аудитории.
* **`20% – 80%`**: Стабильное покрытие постоянной аудитории канала.
* **`💎 ≥ 100%`**: Ролик набрал больше просмотров, чем вся база подписчиков канала. Видео вирусится на холодную аудиторию.

## 4. 🧠 AI-Разбор виральности (Google Gemini)

Нажмите кнопку **«🧠 AI Разбор»** в интерфейсе или отправьте команду `/explain <номер>` в Telegram-боте. Модель Gemini проводит глубокую деконструкцию видео по 4 параметрам:

1. **🎯 Вердикт (Verdict)**:
   - Точная, емкая формулировка фундаментальной причины взлета ролика (психологический триггер, смена парадигмы, утилитарный интерес).
2. **🎣 Хук и упаковка (Hook & Packaging)**:
   - Разбор кликабельности обложки, структуры заголовка, формулы любопытства и удержания первых 30 секунд.
3. **🔥 Оседланный тренд (Trend Alignment)**:
   - Какую макро- или микро-волну в индустрии поймал автор (например, «замена дорогого софта бесплатными open-source агентами»).
4. **💡 Рекомендация автору (Creator Takeaway)**:
   - Конкретный прикладной рецепт: как переложить идею, механику или формулу этого видео в свой контент.

## 5. 🤖 Команды Telegram-бота

| Команда | Действие |
| :--- | :--- |
| `/menu` | Открыть интерактивное меню с кнопками |
| `/top` | Топ-10 лучших видео с бейджами и быстрыми кнопками разбора |
| `/explain <№>` | Запустить глубокий AI-разбор видео № из топа |
| `/digest` | Сгенерировать свежий Executive-дайджест ниши |
| `/sets` | Посмотреть наборы каналов и переключить активный |
| `/status` | Проверить статус ключей API и расписания |
| `/lang` | Переключить язык (`ru`, `en`, `de`, `fi`, `ka`) |
| `/help` | Краткая подсказка по всем командам |
